Руководство пользователя

Пошаговая инструкция по работе с программой: от первой карточки до анализа связей и выгрузки данных.

Быстрый старт

OSINT Картотека — это один HTML-файл, который открывается в любом современном браузере. Ничего устанавливать не нужно.

  1. Откройте файл index.html двойным кликом или по ссылке «Открыть программу».
  2. Данные сохраняются автоматически в браузере (localStorage) — при повторном открытии картотека на месте.
  3. Чтобы освоиться, нажмите «Загрузить демо» в блоке «Данные» — появятся вымышленные объекты и связи.
  4. Кнопкой «Очистить» можно удалить все данные и начать с нуля.
Первое знакомство удобно начать с режима «Список»: слева — все объекты, клик открывает карточку.

Создание объектов

Объекты — это «карточки» в вашей картотеке: люди, организации, домены или инфраструктура.

  1. Нажмите «+ Новый» в панели «Объекты».
  2. Выберите тип и заполните имя/название (обязательно).
  3. Остальные поля заполняйте по мере появления данных: псевдонимы, дата, Telegram, email, телефон, геолокация, счёт, источники, описание.
  4. Фото: загрузите картинку из файла или вставьте ссылку на изображение.
  5. Нажмите «Сохранить».

Готовую карточку можно отредактировать кнопкой «Редактировать» или удалить кнопкой «Удалить».

Роли и связи

Связи показывают, как объекты соотносятся друг с другом.

  • Нажмите «+ Создать связь» в панели «Связи».
  • Выберите Объект A и Объект B — два разных объекта.
  • Задайте тип связи: владеет, участник, администратор, контактирует, то же лицо, находится в, имеет отношение, прочее.
  • Добавьте комментарий — например, из какого источника взят факт.
На карточке объекта вкладка «Связи» показывает все его отношения. Связь можно удалить прямо оттуда.

Доска-граф

Режим «Доска связей» — визуальная картина всех объектов и ролей.

  1. Переключитесь на вкладку «Доска» сверху.
  2. Перетаскивайте узлы мышью, чтобы расположить их удобно.
  3. Кнопка 🔗 — режим соединения: кликните по двум узлам подряд, между ними создастся связь.
  4. Стрелки между узлами подписываются типом роли.
  5. Кнопка ⚡ — автораскладка, ＋/－ — масштаб, колесо мыши тоже приближает, ⟲ — сброс вида.

Хронология

Режим «Хронология» собирает все даты на одну ось времени.

  • На оси автоматически появляются даты объектов и заметки.
  • Кнопка «+ Событие на оси» добавляет своё событие с датой, описанием и привязкой к объекту.
  • События, связанные с объектом, помечаются 🔗. Клик по карточке открывает объект.

Экспорт и импорт

В блоке «Данные» доступны операции с файлами:

КнопкаЧто делает
Экспорт JSONскачивает полную картотеку (объекты, связи, позиции, события) одним файлом
Экспорт CSVскачивает таблицу объектов, открываемую в Excel/таблицах
Импортзагружает ранее сохранённый JSON обратно в картотеку
Печатьвыводит текущий вид на печать / в PDF
Сохраняйте резервную копию в JSON — это надёжный способ переноса данных между устройствами.

Работа с данными

Полезные приёмы для продуктивного анализа:

  • Поиск — ищите объекты по имени, псевдониму, контакту или геолокации через поле поиска.
  • Фильтр по типу — показывайте только людей, организации, домены или инфраструктуру.
  • Заметки — кнопка «+ Заметка» на карточке добавляет записи в персональную хронологию объекта.
  • Ссылки на источники — храните прямые URL в карточке, чтобы документировать, откуда взят факт.
  • Псевдонимы — фиксируйте все известные имена и никнеймы, чтобы распознавать повторные упоминания.
Работайте ответственно и в рамках закона: используйте только открытые источники и публичные данные.
